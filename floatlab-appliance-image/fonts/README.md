FloatLab Braille is a generated symbol font for the ISO's kmscon display.
It contains U+2800–U+28FF as evenly spaced round dots and U+2580, U+2584,
U+2588 as seamless terminal blocks for scannable QR codes. All text falls
through to IBM Plex Mono; other Unicode falls through to Unifont.

Regenerate with Python and FontTools:

```sh
python3 scripts/generate-braille-font.py
```

The outlines are original geometric shapes, generated by that script.
